# AURA v0.12 — проверка на Windows перед распространением

Автоматические тесты выполняют переносимую логику и фикстуры. Ни один пункт аппаратной матрицы ниже не считается пройденным только из-за успешной сборки на Linux. Результаты и конкретные версии Windows/драйверов/модели оборудования нужно записать в отдельный QA-отчёт.

## Матрица

- Windows 10/11 x64; обычный пользователь и администратор, включая ввод другого аккаунта в UAC.
- Intel с доступными RAPL и Intel с BIOS lock/необъявленным пределом; AMD должен явно отказать в PBO-записи.
- Две модели NVIDIA, встроенная+дискретная GPU, две одинаковые NVIDIA; PNP/NVAPI/DXGI должны указывать на один GPU.
- Один/два монитора, разные DPI 100/150/200%, монитор слева с отрицательными координатами, горячее подключение, HDR.

## Запуск, настройки и авторизация

- Чистый запуск EXE, один экземпляр, значок, трей и полный выход. Секретов в журналах нет.
- Прототип явно обозначен; его демо-данные не показываются в Server/LocalDevelopment.
- Локальная серверная сборка: аккаунт, неверный пароль/ключ с повтором, одноразовая активация, вход после выхода без нового ключа, отзыв, другое устройство, сохранение DPAPI.
- Проверка срока при запуске и через 15 минут; при недоступном сервере допускается только неподдельный грант не старше 24 часов. HTTP 401/403 не разрешает офлайн-возврат.
- Повреждённый settings.json сохраняется отдельной копией; пропущенные/null-поля безопасны; удалённые игры остаются удалёнными. Переключатели эффектов и применения при запуске независимы.
- Проверить CRUD/import/export профилей, некорректные диапазоны/дубликаты, ручную правку во время игровой сцены и возврат после потери фокуса.

## Дисплей и прицел

- До изменений записать гамма-кривую, Vibrance и DRS-настройку игры; после возврата должны совпасть исходные значения, а не заводские defaults.
- Переключение монитора затрагивает только выбранное устройство; отключённый монитор не вызывает запись его базы на другое устройство.
- Смена разрешения: сохранить/отказаться/дождаться 15 секунд/потерять фокус/отключить монитор. Неподтверждённый режим возвращается. Сравнить активный и сохранённый режим Windows.
- Масштабирование: исходное значение сохраняется до записи, возвращается после перезапуска AURA. Сравнить QueryDisplayConfig и реальное изображение.
- Все четыре формы прицела, gap/outline/размер/цвет: превью соответствует оверлею. Проверить центр на каждой комбинации DPI. Эксклюзивный полноэкранный режим отдельно.

## Игровые карточки, оверлей и серии v0.12

- Проверить переход игра A → игра B → рабочий стол, выход процесса и оба правила Alt-Tab. Прицел и оверлей не изменяют общие настройки и сохранённую карточку.
- До игры записать фактические гамма-кривые и raw DVC на целевом и прежнем активном мониторе. После возврата сравнить значения. Отдельно проверить EffectsEnabled=false и ApplyProfileOnStartup=false.
- Ошибка возврата, аппаратная операция с занятым gate, потеря монитора и смена физического устройства: снимки сохраняются, новый цвет не перезаписывает незавершённый снимок. Принудительное завершение/повторный запуск в той же загрузке и после reboot.
- Все горячие клавиши при свёрнутом приложении, удержание клавиши, занятое сочетание, отключение и освобождение при выходе; модальные диалоги не принимают эти действия.
- OSD: углы, размер/непрозрачность, смешанный DPI, клик сквозь окно, отсутствие активации, отрицательные координаты, отключение монитора. Игры DX11/DX12/Vulkan, оконный/безрамочный/эксклюзивный режим — отдельные результаты, без общего обещания совместимости с античитами.
- Измерить влияние самой AURA на FPS и CPU/GPU при выключенном/включённом OSD. Сверить имя источника GPU; оно может отличаться от GPU рендера игры на системе с несколькими адаптерами.
- Свежесть FPS: остановка кадров, закрытие игры, задержки CSV; generated/invalid строки, несколько PID/swapchain. Нет выдуманных значений при ошибке ETW. Во время Benchmark Lab работает один захват AURA, чужие сессии сохраняются.
- Серии 3/5: ручной возврат к одной сцене, отменённый прогон, неполная серия, дубликат номера, изменение условий/версий/разрешения, слишком короткая запись. Несопоставимые серии не показывают подтверждённый прирост. Все завершённые прогоны сохраняются.
- Датчики записываются и при свёрнутой AURA; остановка/выход ждут завершения сборщика. Импорт старой истории и сохранение старого settings.json проверяются отдельно. Переключение swapchain меняет просмотр результата, а не сохранённую основную запись серии.

## CPU/GPU и завершение программы

- Записать исходные raw MSR/P0 значения, в том числе дробное отрицательное смещение GPU. Дважды применить один профиль без перезагрузки: значения не должны накапливаться.
- После возврата исходные raw значения совпадают. При недоступном датчике возврат остаётся возможным.
- Отмена на базовом, промежуточном и финальном этапе; выход/выход из аккаунта/ошибка UI во время теста. Окончание ожидает остановки нагрузки и подтверждения возврата.
- Потеря датчика, неверный результат вычислений, слабая GPU-нагрузка, перегрев, device removed/TDR. При ошибке возврата оба сообщения и снимок сохраняются; успешный откат не показывается.
- Убить процесс во время теста, затем запустить AURA в той же загрузке: возврат по сохранённому устройству. После reboot старая база не записывается.
- CPU/GPU/reset/startup/display не выполняют конфликтующие записи одновременно. Автоприменение включается только вручную.
- PawnIO: отказ UAC, недоверенная подпись, замена файла до проверки, отсутствие сети для проверки цепочки, запрос reboot, повторный запуск. Установщик не убивается посреди установки.
- Проверка 20/30/120 секунд и длительный внешний стресс-тест; затем реальные игры. CPU-score не выдаётся за прирост FPS.

## Windows Tuner

- На одноразовой Windows VM снять исходные значения/типы/отсутствие ключей, состояния служб/задач, AC/DC-параметры и активную схему питания, NTFS/BCD/reserved storage.
- Минимальный/Сбалансированный/Расширенный (внутренние Low/Medium/Ultra): 25/41/61 пункт; нет Danger. Проверить точный preview, ошибки, skipped и историю текущей операции.
- Возврат затрагивает только журнал AURA; пустой журнал ничего не меняет. Сравнить все исходные значения после возврата.
- Прерывание до/после каждой записи, отказ доступа/диска, повторный запуск, частичная ошибка возврата. Неполный снимок не удаляется. Повторное применение после частичного возврата сохраняет свежую базу возвращённых записей.
- Попытаться подложить пользовательский CLIXML, ссылку/junction, ACL с записью Users и заменить скрипт до UAC. Скрипт выполняется из проверенных байтов; недоверенный журнал отвергается.
- Проверить HKCU именно исходного SID при UAC под другим администратором.
- Четыре удаления AppX и отключение гибернации недоступны. Быстрый запуск не меняет тип/размер уже включённой гибернации.
- Реальная применимость политик проверяется отдельно для каждой редакции/сборки Windows.

## Диагностика и выпуск

- PresentMon CSV каждой поддерживаемой версии: несколько swapchain, разные процессы, пропущенные/сгенерированные кадры и длинный stall. Результат не смешивает потоки; ETW очищается только для сессии AURA.
- Отмена/timeout PresentMon, большие stdout/stderr; чужой PresentMon продолжает работать. Системный журнал без доступа/с ошибкой не показывает «проблем нет».
- Проверить группировку событий, даты/источник датчиков, историю/сравнение и экспорт. В JSON нет токенов, паролей, email и ID устройства.
- Выполнить CI на Windows, включая Windows PowerShell 5.1. Он ещё не считается выполненным локальными Linux-тестами.
- Генерировать release-report вместе с текущим EXE. Для коммерческого выпуска: HTTPS Server-режим, доверенный закреплённый ключ, действительный Authenticode, лицензии/исходники сторонних компонентов и пройденная матрица. Текущий неподписанный Prototype предназначен для разработки.
