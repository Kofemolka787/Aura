# AURA v0.10 — исходный код

AURA — 64-битное Windows-приложение на .NET 8/WPF для одного выбранного монитора: цветовые режимы, игровые автопрофили, растянутое разрешение, прицел, диагностика, управляемые твики и аппаратная автонастройка.

## Что добавлено в v0.10

- **Живой поиск процессов в Benchmark Lab**: фильтрация по любой части имени без учёта регистра (`Rus`, `rust` или `Client` находят `RustClient.exe`).
- **Monitor Pro удалён полностью**: из навигации, интерфейса и исходного кода убраны экран и отдельный слой DDC/CI/ICC-управления.
- **Windows Tuner восстановлен полностью**: 82 отдельные настройки из референсов, поиск по названию и описанию, категории, метки Safe / Caution / Danger, профили Low / Medium / Ultra и откат к реально сохранённым исходным значениям.
- **Релизная диагностика**: необработанные ошибки записываются в `%LocalAppData%\AURA\Logs\aura.log`, повреждённый `settings.json` сохраняется рядом как резервная копия, а каталог твиков проверяется при старте.

- **Smart Auto Overclock без привязки к одной модели**:
  - NVIDIA: AURA перебирает все найденные NVAPI-адаптеры, выбирает видеокарту с редактируемым P0 Graphics Clock, тестирует offset ядра шагами по 15 MHz и автоматически откатывается при перегреве или сбое;
  - AMD: поколение определяется самим подписанным RyzenSMU-модулем. Для совместимых Ryzen/Threadripper/APU применяется соответствующий PBO/SMU-адаптер и индивидуальная база PPT/TDC/EDC;
  - Intel: на процессорах с доступным незаблокированным Package RAPL AURA тестирует PL1/PL2 в границах, объявленных CPU. На моделях с закрытым множителем это оптимизация штатного Turbo, а не поддельная «разблокировка»;
  - перед каждой записью проверяются производитель, поколение, аппаратный интерфейс, BIOS-lock, редактируемый диапазон и датчик температуры;
  - встроенные PawnIO-модули проверяются по SHA-256 перед загрузкой; память, ручное напряжение, BCLK и фиксированный множитель не меняются.
- **PawnIO одной кнопкой**: официальный PawnIO 2.2.0 и модули 0.2.11 уже встроены. При первом CPU-тесте общая кнопка вызывает UAC, устанавливает подписанный драйвер и продолжает проверку; отдельной кнопки загрузки нет.
- **Корректная работа с несколькими GPU**: для разгона и телеметрии NVIDIA имеет приоритет над встроенной графикой.
- **Benchmark Lab**: запись FPS и фреймтаймов запущенной игры через официальный PresentMon, средний FPS, 1% low, P95/P99 и скачки кадра.
- **Smart Audit** и **Stutter Doctor**: проверка температур, памяти, диска, игровых параметров Windows и событий TDR/WHEA.
- **Windows Tuner**: профили Low Performance / Medium Performance / Ultra Performance с отдельным подтверждением применения и UAC.
- Дублирующая вкладка «Профили» и функционал телефона удалены.

## Проверка и сборка

Требования: Windows 10/11 x64 и .NET 8 SDK.

```powershell
.\scripts\build-release.ps1
```

Скрипт сверяет SHA-256 встроенных инструментов, запускает smoke-тест каталога твиков и публикует `release-v0.10/Aura.exe`. Это самостоятельный ReadyToRun single-file EXE: дополнительные DLL и папки рядом не нужны. Используемые утилиты и подписанные PawnIO-модули встроены в EXE и извлекаются AURA только при необходимости с проверкой SHA-256.

Ручная проверка экранов и аппаратных функций описана в `RELEASE-CHECKLIST.md`.

## Реальные границы совместимости разгона

- Нельзя программно гарантировать разгон буквально любого процессора: старые поколения могут не иметь PBO/RAPL, Intel non-K имеет закрытый множитель, OEM BIOS может поставить аппаратный lock, а VBIOS/драйвер NVIDIA может запретить P0 offset. AURA в таких случаях показывает точную причину и ничего не записывает.
- Короткий автотест снижает риск, но не гарантирует абсолютную стабильность во всех играх. Перед тестом нужно закрыть игры, античит и тяжёлые приложения.
- AURA не обходит античит. PawnIO устанавливается только по явному подтверждению и UAC; при сообщении античита о несовместимости закрой AURA и перезагрузи компьютер.
- GPU-offset, AMD PBO и Intel PL1/PL2 не прошиваются в BIOS и возвращаются драйвером/прошивкой после перезагрузки.
- Установка подписанного драйвера не может обходить UAC. Если Windows потребует перезагрузку после первого нажатия, открой AURA после перезагрузки и нажми ту же кнопку ещё раз.

## Демо-вход

- логин: `demo@aura.app`
- пароль: `aura2026`
- ключ: `AURA-30D-DEMO-2026`

Демо-авторизация работает локально и предназначена только для прототипа. Для продажи нужен отдельный HTTPS API, серверная база аккаунтов/подписок, Argon2id-хеши паролей, одноразовые хешированные ключи, отзыв сессий и серверная проверка срока/привязки устройства. Пароль нельзя хранить в EXE или локальном JSON.

## Перед публичной продажей

- заменить `DemoAuthService` реальным HTTPS API и убрать демо-кнопки;
- подписать `Aura.exe` сертификатом Authenticode, иначе SmartScreen может показывать предупреждение неизвестного издателя;
- прогнать `RELEASE-CHECKLIST.md` минимум на NVIDIA + AMD Ryzen и NVIDIA + Intel, а также на Windows 10 и Windows 11;
- подготовить политику конфиденциальности, условия подписки и канал поддержки.
